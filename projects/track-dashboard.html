INTRODUCTION

项目介绍

赛道洞察数据产品，把飞书 Base 中的业务资料同步为可审计快照，再通过 Insight API 和瀑布流/产品库呈现。

本地快照和代码验证不等于真实 Base 内容、权限、Gateway、OSS 和生产发布已完成；数据范围需现场重验。

ARCHITECTURE

架构概览

数据同步层

Feishu Base -> sync Worker，按应用身份读取已批准范围并生成最近成功快照。

数据与查询层

PostgreSQL 保存同步快照和产品/Insight 组合，Insight API 提供稳定查询合同。

产品展示层

Next.js 瀑布流、赛道阅读和产品库消费 Insight，而不是直接依赖底层 Product 表语义。
