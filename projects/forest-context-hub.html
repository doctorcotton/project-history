项目介绍

企业级上下文、指标和 Agent 工具入口，统一承载本地工作台、CLI、插件、数据查询适配、凭据边界和异常告警能力。

ARCHITECTURE

架构概览

入口与工作台层

CLI、Codex Relay、本地 Web Workbench 和插件提供统一入口，负责用户交互、任务和制品生命周期。

领域治理层

以数据上下文、指标口径、来源身份和权限策略组织查询，明确 Draft、已发布和不可比状态。

Provider 与可靠性层

通过 Guandata/飞书等适配器隔离外部协议，配合 OAuth PKCE、Kafka/Outbox、并发限制、Webhook 告警和运行时生命周期。

PROGRESS

当前完成进度

本地工作台、CLI 认证、告警和治理能力已成型，真实外部指标发布与 UAT 仍受数据/凭据门禁约束。

已形成

  • Codex 优先的本地 Web Agent 工作台、制品生命周期和 workspace 基础已形成。
  • FCH CLI OAuth PKCE 单入口登录、Webhook 异常告警和 Kafka/Outbox 可靠性能力已推进。
  • 外部查询的身份、指标状态、并发和请求级凭据边界已有明确约束。

进行中

  • 发布指标、真实 Guandata 查询和数据产品入口的闭环。
  • 跨组件运行态、告警和生产配置的持续验证。

下一步

  • 完成 Owner/Steward 对指标口径和来源身份的批准。
  • 在真实 Gateway、外部 Provider 和部署环境中完成 UAT。

以上是基于当前项目资料和历史证据的阶段判断，不是发布完成率。
