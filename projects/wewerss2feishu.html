INTRODUCTION

项目介绍

RSS/WeWe RSS 到飞书内容的本地同步项目，支持订阅源接入、内容转换、发送取消、缓存和容器化交付边界。

本地 RSS 静态验证不等于真实飞书发送、容器运行和多副本状态一致性已验收。

CURRENT STAGE

当前阶段

RSSHub 接入和静态验证已完成，持久状态、容器交付和多副本扩展边界仍需继续验证。

历史证据状态：已推进；最近证据：2026-08-07。

ARCHITECTURE

架构概览

订阅与转换层

Node/Express 主应用接入 RSSHub/订阅源，将 RSS 内容转换成飞书可消费的结构化消息。

发送与缓存层

发送流程支持取消和生命周期控制，Markdown/卡片转换缓存按对象和运行时边界隔离。

交付与状态层

Docker runtime 和单副本 SQLite/Kustomize 作为当前交付基线；嵌套 fork 作为独立实现，不能混淆部署合同。

PROGRESS

当前完成进度

RSSHub 接入和静态验证已完成，持久状态、容器交付和多副本扩展边界仍需继续验证。

已形成

  • Node/Express 发送取消、转换缓存和 Docker runtime 方向已有架构收口。

进行中

  • 持久化缓存/SQLite 状态与发送生命周期的一致性。
  • 主应用与嵌套 fork 的边界、镜像和部署配置核对。

下一步

  • 完成真实订阅源、飞书身份和容器环境回读。
  • 若需要水平扩展，先明确数据库/OSS/队列状态边界再改部署形态。

以上是基于当前项目资料和历史证据的阶段判断，不是发布完成率。
