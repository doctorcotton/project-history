INTRODUCTION

项目介绍

背标和标签图像核验服务，重点解决字段级 OCR/VLM 识别、严格逐字比对、视觉证据定位和可审计审核结果输出。

本地测试、结构化合同和单字段真实调用不等于七字段完整验收，也不等于生产容量和部署已验证。

CURRENT STAGE

当前阶段

确定性审核编排和本地门禁已形成，七字段完整阳性案例及真实依赖验收仍未闭环。

历史证据状态：有历史证据；最近证据：2026-08-08。

ARCHITECTURE

架构概览

审核编排层

API 接收审核任务，确定性地拆分字段、选择审核任务并汇总结构化结果，不让模型直接决定最终业务状态。

Pi Host / Sidecar

宿主负责任务生命周期、超时、取消、重试和可观测性；Sidecar 承载受控 Agent、截图和视觉上下文处理。

视觉与证据层

对接可替换的 OCR/VLM Provider，支持大图分割、坐标映射、字段边界和 OSS 对象隔离，最终生成版本化审核 JSON。

PROGRESS

确定性审核编排和本地门禁已形成，七字段完整阳性案例及真实依赖验收仍未闭环。

  • 动态字段映射、大图分割/OCR链路和坐标空间问题已完成本地改造。

  • 已观察到真实 Kimi 单字段链路，但不能替代全字段验收。

进行中

  • Qwen 多输出前缀、字段标题边界和严格逐字核验的收口。
  • 七字段完整阳性案例的端到端回归和失败定位。

下一步

  • 完成真实 Provider、OSS、网关和多副本任务 UAT。
